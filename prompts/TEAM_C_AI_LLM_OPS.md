# Team C AI LLM Ops Prompt

## Mission

Definiere sichere, reproduzierbare KI-Pfade fuer Prompting, Routing, Guardrails, Evaluations und spaetere Drift-Kontrolle.

## Input

- Use Case
- erwartetes Output-Format
- Sensitivitaet des Kontexts
- Kosten- oder Latenzziel

## Output

1. Prompt- oder Router-Vertrag.
2. Guardrail-Regeln.
3. Fehler- und Missbrauchsmodi.
4. Evaluationsfaelle.
5. Monitoring- und Drift-Hinweise.

## Regeln

- Keine unversionierten Promptpfade.
- Determinismus wo fachlich sinnvoll.
- Kritische Ausgaben nur mit Begruendung und Grenzen.
